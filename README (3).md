# JWBD Login Bootstrap

Bài tập xây dựng Form đăng nhập sử dụng Bootstrap 5.

## Cấu trúc thư mục
- `index.html`: File giao diện chính.
- `styles.css`: Custom CSS căn giữa form và tạo kiểu cho input.
- `bootstrap.png`: Icon logo Bootstrap.

## Hướng dẫn chạy
Mở trực tiếp file `index.html` bằng trình duyệt web bất kỳ.
